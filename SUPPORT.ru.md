# Поддержка

[English version](SUPPORT.md)

Проект поддерживается автором по мере доступности.

Используйте:

- **GitHub Discussions** для вопросов по использованию и настройке;
- **GitHub Issues** для воспроизводимых ошибок и конкретных предложений;
- **GitHub Security Advisories** для уязвимостей.

Перед обращением выполните:

```bash
sudo ./postfix-relay-rescue.sh status example.com
sudo postfix check
sudo postqueue -p
```

Очистите вывод. Никогда не публикуйте SMTP-пароли, полный `sasl_passwd`,
частную переписку, имена клиентов и другие секреты.

Репозиторий не предоставляет коммерческое аварийное сопровождение,
гарантированное время ответа или услугу удаления из Spamhaus.
